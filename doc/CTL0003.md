CTL0003 - Fix method name to match some property raising NotifyPropertyChanged event
====================================================

When using Catel.Fody's `OnPropertyChanged` handler naming convention, a private method named `On{PropertyName}Changed` is expected to correspond to an existing property named `{PropertyName}` in the same class. If no such property exists (either declared directly or exposed via the `[Expose]` attribute), it likely indicates a typo or a missing property.

Instead of having a method with no corresponding property:

```
public class MyModel : ObservableObject
{
    private void OnMyPropertyyChanged()  // typo: "Propertyy" instead of "Property"
    {
        // This handler will never be called
    }
}
```

consider fixing the method name or adding the corresponding property:

```
public class MyModel : ObservableObject
{
    public string MyProperty { get; set; }

    private void OnMyPropertyChanged()
    {
        // This handler is now correctly associated with MyProperty
    }
}
```

This analyzer will investigate all private methods in classes inheriting from `Catel.Data.ObservableObject` whose names match the `On{PropertyName}Changed` pattern. If no corresponding property is declared in the class (or exposed via the Catel.Fody `[Expose]` attribute), the analyzer will report a warning.
