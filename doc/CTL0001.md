CTL0001 - Use InvokeTaskAsync instead of InvokeAsync for async tasks
====================================================

When invoking tasks using the `IDispatcherService`, use `InvokeTaskAsync(async () => ...)` instead of `InvokeAsync(async () => ...)`. Using `InvokeAsync` with an async delegate results in a fire-and-forget pattern where exceptions are swallowed and the caller cannot await the completion of the task.

Instead of using this code:

```
await _dispatcherService.InvokeAsync(async () =>
{
    await DoSomethingAsync();
});
```

consider using:

```
await _dispatcherService.InvokeTaskAsync(async () =>
{
    await DoSomethingAsync();
});
```

This analyzer will investigate all invocations of `InvokeAsync` on any type. When the first argument is an async lambda expression (`async () => ...`), the analyzer will report an error.
