CTL0008 - Use ArgumentNullException.ThrowIfNull for argument check
====================================================

Starting from .NET 6, use the new `ArgumentNullException.ThrowIfNull` method instead of `Catel.Argument.IsNotNull` for null argument checks. The built-in `ArgumentNullException.ThrowIfNull` is more efficient as it is implemented natively and does not require an additional library dependency.

Instead of using this code:

```
public MyClass(MyService service)
{
    Argument.IsNotNull(() => service);
    ...
}
```

consider using:

```
public MyClass(MyService service)
{
    ArgumentNullException.ThrowIfNull(service);
    ...
}
```

This analyzer will investigate all invocations of `Argument.IsNotNull`. When such a call is found, the analyzer will report a warning. A code fix is available to automatically replace the call with `ArgumentNullException.ThrowIfNull`.
