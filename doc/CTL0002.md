CTL0002 - Use RaisePropertyChanged(nameof(PropertyName)) instead of expression-based overload
====================================================

Use `RaisePropertyChanged(nameof(MyProperty))` instead of `RaisePropertyChanged(() => MyProperty)` to improve performance and decrease allocations. The expression-based overload creates a lambda expression at runtime which causes unnecessary memory allocations and is slower to execute.

Instead of using this code:

```
RaisePropertyChanged(() => MyProperty);
```

consider using:

```
RaisePropertyChanged(nameof(MyProperty));
```

This analyzer will investigate all invocations of `RaisePropertyChanged`. When the first argument is a lambda expression starting with `() => `, the analyzer will report a warning.
