CTL0011 - Provide log on throwing exception
====================================================

When throwing an exception in a class that uses Catel's `ILog`, use `Log.ErrorAndCreateException` instead of directly throwing. This ensures that the exception is logged before being thrown, which helps with diagnostics and debugging.

Instead of using this code:

```
public class MyClass
{
    private static readonly ILog Log = LogManager.GetCurrentClassLogger();

    public void DoSomething()
    {
        throw new InvalidOperationException("Something went wrong");
    }
}
```

consider using:

```
public class MyClass
{
    private static readonly ILog Log = LogManager.GetCurrentClassLogger();

    public void DoSomething()
    {
        throw Log.ErrorAndCreateException<InvalidOperationException>("Something went wrong");
    }
}
```

This analyzer will investigate all `throw` statements in classes that declare a static `ILog` field. When an exception is thrown directly (without using `Log.ErrorAndCreateException`), the analyzer will report a warning. A code fix is available to automatically replace the `throw new Exception(...)` pattern with the `throw Log.ErrorAndCreateException<TException>(...)` pattern.
